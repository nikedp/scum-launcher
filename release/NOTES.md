SCUM Lab Launcher 0.1.57: отключение модов для других серверов, порядок в окне.

- «Моды SCUM Lab» → «Отключить моды»: файлы сборки убираются из игры (переносятся в SCUMLabLauncherData\parked), SCUM запускается через Steam для любых серверов. «Вернуть моды» — обратно, с проверкой SHA256.
- При запуске лаунчер сам показывает установленную версию и состояние модов; кнопка запуска подписана по режиму («Играть на SCUM Lab» / «Запустить SCUM»).
- Удалённые вручную файлы больше не блокируют «Синхронизировать» — недостающее загружается заново; после обновления SCUM синхронизация тоже не блокируется.
- Сборка модов не изменилась (MH-6 как в 0.1.56).
