SCUM Lab Launcher 0.1.7: исправлено обнаружение локального реестра.

- Исправлен корневой каталог внутри создаваемого PAK реестра: UE4 использует ключ /, а прежний упаковщик записывал пустую строку.
- Старый PAK мог монтироваться, но AssetRegistry.bin внутри него не находился через файловый поиск движка. Из-за этого новые записи не были доступны игре.
- После обновления лаунчера закройте игру и снова нажмите «Синхронизировать»: будет пересоздан локальный PAK реестра. Одного обновления EXE недостаточно.
- Очистка клиентских данных для этого исправления не нужна. Игровой PAK стула и дельта регистрации не менялись.
- Сервер должен запускаться с -fileopenlog -nobattleye для модового клиента.

Прошли 50 self-tests. Дополнительно нативный UE4.27.2 воспроизвёл проблему: старый пакет не разрешает путь AssetRegistry.bin, исправленный разрешает. Исправленный серверный пакет смонтирован, остров загружен; видимость рецепта, изготовление и размещение ещё требуют клиентского теста.

Обновление доступно кнопкой «Обновить лаунчер» в версиях 0.1.2 и новее.
