Первая экспериментальная версия Windows-лаунчера SCUMLab.

- Синхронизация PAK по манифесту GitHub Releases и SHA256.
- Проверка совместимости со Steam Build игры.
- Локальная сборка реестра из файлов установленной SCUM.
- Резервные копии и откат управляемых файлов.
- Запуск клиентской SCUM через Steam.

Самопроверки установки и отката пройдены. Игровой тест мебели ещё предстоит; экспериментальная установка требует явного выбора в лаунчере. Файлы мира не откатываются этой программой.

Скачайте SCUMLabLauncher.zip. Архив не требует установки; распакуйте его перед запуском EXE.
