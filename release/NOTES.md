SCUM Lab Launcher 0.2.3: загрузка сборки по локальной сети.

- Если в манифесте сборки указан адрес в локальной сети (`lanFeed`, только частные IPv4-адреса), лаунчер сначала качает файлы оттуда — дома это сотни МБ/с вместо скорости домашнего интернета.
- Манифест по-прежнему загружается по HTTPS с внешнего адреса, и каждый файл проверяется по его SHA256 — подменить файл через локальную сеть нельзя.
- Если локальная сеть недоступна (игрок не дома), лаунчер через 3 секунды переключается на внешний адрес; в журнале видно, откуда скачан файл.
